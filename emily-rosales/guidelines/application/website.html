Keep it consistent

Do

04

Use with AI

  • Attach the AI context file and this Website page
  • Name the audience, the one point, and the next step
  • Ask for a draft in Emily's voice
  • Do not invent clients, results, credentials, fees, or quotes
  • Check the voice, the layout, and any portrait before use
