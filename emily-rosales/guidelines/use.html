01

How it works

  1. 01
    Open

    Start a new chat for one task.

  2. 02
    Paste

    Give the AI the brand context first.

  3. 03
    Ask

    Name the channel, topic, and goal.

  4. 04
    Review

    Check facts, voice, and images before using anything.

02

Starter prompts

LinkedIn

Write a post

Brand Therapy OS: https://brandtherapy.florianp.com/emily-rosales/guidelines/
AI context: https://brandtherapy.florianp.com/emily-rosales/guidelines/ai-context.md

Write a LinkedIn post for Emily Rosales. Audience: established consultants and advisors. Make one useful point about positioning. Start with the reader's situation. Keep it warm, plain, and precise. End with one practical next step. Do not invent clients, results, or credentials.

Website

Sharpen a page

Brand Therapy OS: https://brandtherapy.florianp.com/emily-rosales/guidelines/
AI context: https://brandtherapy.florianp.com/emily-rosales/guidelines/ai-context.md

Review this web page for Emily Rosales. Rewrite the headline and opening so an established consultant understands the value in one read. Keep the promise: clarity before visibility. Return the new headline, the opening paragraph, and what you changed.

Email

Draft a note

Brand Therapy OS: https://brandtherapy.florianp.com/emily-rosales/guidelines/
AI context: https://brandtherapy.florianp.com/emily-rosales/guidelines/ai-context.md

Draft a short email note for Emily Rosales. Structure: one observation, one practical idea, one useful next step. Keep it calm and direct. No hype, no urgency, no invented proof.

Review

Check a draft

Brand Therapy OS: https://brandtherapy.florianp.com/emily-rosales/guidelines/
AI context: https://brandtherapy.florianp.com/emily-rosales/guidelines/ai-context.md

Check this draft against Emily Rosales's brand. Flag anything that sounds hyped, generic, or unclear. Confirm it makes one point, starts with the reader, and keeps confidence grounded. Suggest exact line edits.

03

Final check

  • Use verified facts and current brand pages
  • Keep voice and visual rules consistent
  • Do not invent credentials, results, quotes, fees, or endorsements
  • Use approved portraits of Emily only
