02

Decision A, decided: A2 calibrated brass approved

Approved 2026-06-13. The dot is the focal point of the mark, and measured brass sat on coral's lightness step (L* 59.0 vs 57.3) with the weakest contrast on ivory of any element, 2.70∶1. Calibration deepens brass to L* 54 at the same hue and chroma; dot-on-ivory now reads 3.21∶1. Production set regenerated with CALIBRATED = True; all PNG/SVG masters carry the new value. Nothing else in the palette changed.

04

Decision C, decided: the wordmark — V7 and V8, both locked

Round 1 set the name in two letterspaced caps lines; rejected against the D2 source. Round 2 used Archivo, humanist: the C did not echo the mark. This round switched to Outfit 600: geometric, monoline, the C is essentially a circle with radial terminals, so the letterform and the mark share one geometry. Public name only: Cannabis Chamber Of Commerce; CCC stays internal shorthand.

Eight alignments were studied (V1–V8), all anchored to MEASURED ink bounds (top 41.02, midline 447.76, bottom 854.49) — the parametric bounding box is 104 units taller because the lower modules sit at 30°, which was the misalignment caught in R3-fu3. V7 (three lines) and V8 (two lines) are locked. Both are math-perfect dual alignment: cap of line 1 on the measured mark top, baseline of the last line on the measured mark bottom, zero shift. Each ships in two treatments — T1 ink and T2 tricolor.

Studies that led here

V1–V6 explored small / snug / top / bottom / two-line / one-line placements and were set aside: V1 read as caption-scale, V3 and V4 hung off one edge, V5 and V6 traded the three-C echo for compactness. The edge-pinned pair (V7 / V8) keeps the name co-equal with the mark at both line counts. Full study set plus construction-guide views in preview/alignment/; anchors measured by measure_rendered_mark.py.

Medallion: pulled, not abandoned

The R3-fu2 medallion was built native-vector (outer_r=540, inner_r=510, cap=56 — all parameters invented from scratch) which violates the source → measure → snap → verify discipline the D2 mark itself was built with. It read “okay” from a distance but won't survive scrutiny. Pulled from the sheet. It will be rebuilt in its own ticket (T-236) against a chosen source raster or a measured existing seal — not invented.

Stacked: not approved

The stacked lockup (mark above a name-centered block) is not part of the approved set. The approved wordmarks are V7 (3 lines) and V8 (2 lines) only. The stacked SVG/PNG files still build but are not presented as a usable logo; if a centered vertical format is ever needed it will be a separate decision, constructed from V7.

Construction, for the record

Cap height is the only knob; the rest follows. Line advance = 1.2 cap. Mark-to-text gap = one dot diameter (122u). Every anchor uses the MEASURED ink bounds — REAL_MARK_TOP = 41.02, REAL_MARK_BOTTOM = 854.49, REAL_MARK_MID = 447.76, REAL_MARK_H = 813.47 — read by measure_rendered_mark.py from png/ccc-mark-1024.png and recorded in png/mark-ink-bounds.json. The parametric box (MARK_H = 916.67) is kept for SVG viewBoxes but never used for alignment. V7 (3 lines, cap = realH/3.4) and V8 (2 lines, cap = realH/2.2) both use edges mode: cap of line 1 = real top, baseline of line N = real bottom by construction (cap = realH / (1 + (N−1) × 1.2)). Values in geometry-production.json under alignment_variants.
