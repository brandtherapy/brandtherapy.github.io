The Viewfinder Bracket

FP's signature visual device. A purple L-shaped corner system for showing clarity and focus. The device has three approved modes: heading corner, focal viewfinder, and image frame.

Recognition test: If someone sees two purple L-shaped corners creating a focal point or framing an image edge, they should think FP before reading any text.

Construction

  • Heading mode: one top-left corner for typography lockups
  • Focal mode: two corners only on photos: bottom-left + top-right, anchored to the focal rectangle inside the image
  • Image mode: two corners only: bottom-left + top-right, sitting outside the image edge with no blur or crop
  • Color: #5A5CF9
  • Arm length: 33% of the adjacent focal rectangle dimension
  • Weight: 3% of image min-dimension (the shorter side). On a 1500×560 hero, that's 17px. On a 1080×1350 portrait, that's 32px.
  • Angles: sharp 90 degrees. No curves, no rounded corners.
  • Focal position: OUTSIDE the focal rectangle, never as a border on the image edge. Inner edge of arm is flush with the focal boundary; arm thickness sits in the blurred area.
  • Image position: OUTSIDE the image edge. No blur, no darkening, no focal rectangle.

Focal-point integration

The bracket needs a focal rectangle to anchor against. The focal point comes from automated detection or manual calibration: never guess.

Source: focal point comes from the brand-asset-intake skill (tools/detect-focal-point.py).

Portrait mode:

  • Detection: dlib 68-point facial landmarks; returns bridge of nose / between eyes
  • When: Florian or any human subject is in frame

Subject mode:

  • Detection: Purple #5A5CF9 region centroid via RGB distance + HSV hue fallback
  • When: concept, object, or metaphor with purple injection

Manual fallback: side profiles or no purple detected -> script returns MANUAL -> use the local focal-point calibrator to click-set.

Bracket placement: focal-x / focal-y from MANIFEST.md determine the focal rectangle. Top-right and bottom-left arms snap to the rectangle edges. Bracket frames the subject's focus area, not the image edges.

Blur treatment

  • Inside frame: full color, full sharpness. No filter.
  • Outside frame (portrait mode): filter: blur(8px) brightness(0.45). Lighter blur so the person isn't visually cut in half.
  • Outside frame (subject mode): filter: blur(12px) brightness(0.3). Stronger contrast, more dramatic focus.
  • Technique: two stacked image layers. Background layer carries the blur+brightness filter. Foreground layer is clip-path: inset() to the focal rectangle. Bracket arms sit on top, positioned by the focal rectangle's outer edges.
  • No separate dark background: the darken effect comes from the brightness filter on the blurred layer, not a flat overlay.

Tiers

  • Primary: focal mode with blur/darken. Hero usage on social, blog thumbnails, email headers, web heroes.
  • Ambient: image mode, bracket only, no blur. Website accents, email footers, presentation slides.

Variants

focal

  • Corners: 2-corner (top-right + bottom-left)
  • Treatment: full blur + darken outside bracket
  • Position: OUTSIDE focal rectangle
  • Use: hero images, social post primary photos, blog thumbnails, web heroes

portrait

  • Corners: 2-corner (top-right + bottom-left)
  • Treatment: portrait mode blur(8px) brightness(0.45)
  • Position: OUTSIDE focal rectangle, framed around face
  • Use: Florian portraits, founder imagery, speaker shots

subject

  • Corners: 2-corner (top-right + bottom-left)
  • Treatment: subject mode blur(12px) brightness(0.3)
  • Position: OUTSIDE focal rectangle, framed around object/concept
  • Use: concept and object imagery. Same 2-corner bracket as focal and portrait. Photos always use 2-corner.

type_lockup

  • Corners: 1-corner (top-left only). Asymmetric L: top arm extending right, short left arm down.
  • Construction: border-top: 4px solid #5A5CF9; border-left: 4px solid #5A5CF9; width: 28px; height: 10px
  • Position: beside or above text, never on a photo
  • Use: eyebrow + headline lockups. Type-only contexts. Replaces horizontal dash.

image

  • Corners: 2-corner (top-right + bottom-left)
  • Treatment: no blur
  • Position: OUTSIDE the image edge
  • Use: website accents, email footers, presentation slides, image-led layouts where the image should remain intact

Rules

  1. On photos: 2-corner only (top-right + bottom-left). Never 1-corner. Never 4-corner.
  2. 1-corner is reserved for typography lockups (eyebrow + headline).
  3. Focal mode bracket sits OUTSIDE the focal rectangle. Never as a border on the image.
  4. Focal mode uses the same image on both layers: inside sharp, outside blurred + darkened.
  5. Image mode sits outside the image edge and never blurs or crops.
  6. Focal point determines focal-mode bracket placement. Read from MANIFEST.md, never guess.
  7. Arm length is exactly 33% of the adjacent focal rectangle or image-edge dimension.

Critical: heading = 1-corner type-only. focal = 2-corner inside image with blur/darken outside. image = 2-corner outside image edge with no blur. 4-corner is removed from the signature system.

Related signature devices

The viewfinder is the primary signature device. FP also uses these secondary devices, working in concert:

  • Purple period (.): accent-colored period at the end of every brand headline. Cheapest brand signal, most consistent.
  • Purple dot in FP wordmark: the period after "FP" in the logo mark uses the same accent.
  • Grain texture: 0.03 opacity grain overlay. Prevents the brand from feeling sterile or clinical.

See IDENTITY.md section "Signature Device" for the brief overview. This file is the construction spec for image-generation, layout work, and asset QA.
