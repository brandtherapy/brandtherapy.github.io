The Seam

Status: temporary stylescape accepted 2026-07-21, pending Identity Gate 4

The Seam is translucent purple glass that adapts to where it goes. It has no fixed signature shape. It lines up with the host form it meets: a jacket thread or seam, a UI edge, a frame rule, a print margin. The signature is adaptive placement and glass material, not a mark and not literal water.

Geometry

None fixed. No rings. No discs. No Venn. No eye. No water pour sculpture.

Follow the existing line of the host: stitch, seam, edge, rule, corner. Small. Subtle. Almost missed on first glance.

Color

  • Seam Violet (translucent purple glass) is the main brand color.
  • Signal Cobalt and Civic Red only as tiny refraction hints at glass edges.
  • Neutrals: Carbon, Ink Violet, Bone, Oxidized Silver.

Use

  • Tiny adaptive accents on media and wardrobe hosts: along a lapel thread,

seam, UI chrome edge, magazine rule, podcast frame. Glass quality, subtle.

  • Never a logo lockup with the name.
  • Never a large pour, puddle, ribbon, or sculptural water mass.
  • Never rings, discs, badges, pins, or embroidery logos.

Failure conditions

  • Treated as a finished logo system.
  • Fixed signature shapes (rings, discs, Venn, eye).
  • Literal water / liquid sculpture dominating the frame.
  • Large purple glass masses.
  • Clothing logos, pins, badges.
  • MasterCard red/blue circles.
  • Sci-fi HUD or neon glow soup.
