Use with AI

Give AI the right brand context, then review the result before using it.

On this page
  1. How it works
  2. Starter prompts
  3. Final check

01

How it works

  1. 01
    Open

    Start a new chat for one task.

  2. 02
    Paste

    Give the AI the brand context first.

  3. 03
    Ask

    Name the channel, topic, and goal.

  4. 04
    Review

    Check facts, voice, and images before using anything.

02

Starter prompts

Starter prompts are added once the brand adds a QUICKSTART. Until then, paste the brand context and describe the task.

03

Final check

  • Use verified facts and current brand pages
  • Keep voice and visual rules consistent
  • Do not invent credentials, results, quotes, or endorsements
  • Never use the temporary stylescape as a face reference
