How to use them

  • Replace only the headline and accurate supporting line
  • Use the image-led version with a current brand photograph
  • Use a typographic version when no portrait is needed
  • Keep one message and one clear next action

03

Print setup

Standard preview

  • 24 x 36 inch ratio
  • 0.125 inch bleed when printed
  • 0.25 inch safe area
  • 300 dpi print export
  • CMYK proof before ordering

Content rules

  • One dominant statement
  • Accurate event information
  • No filler logo
  • Use current brand photography
  • Check dates, links, size, and print proof before ordering
